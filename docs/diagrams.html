1. System Architecture (Three-Tier)

flowchart TB
  subgraph P["Presentation Layer — PWA (Browser / Mobile)"]
    UI["HTML5 · CSS3 · Bootstrap 5 · JS
Pages: Landing, Login, Dashboard,
Assessment, View, History, Profile"]
    SW["Service Worker
(app-shell cache)"]
    IDB[("IndexedDB

    AUTH["Auth (JWT + bcrypt)"]
    ASMT["Assessments / Media / Reports"]
    SYNC["Sync Service"]
    PDF["PDF Generator (PDFKit)"]
  end
  subgraph D["Data Layer"]
    DB[("SQLite Database
engineers · assessments · media
contacts · activity_log")]
    FS[("File Storage
uploaded images / videos")]
  end
  UI <--> SW
  UI <--> IDB
  UI -->|"HTTPS JSON / multipart"| AUTH
  UI --> ASMT
  IDB -->|"on reconnect"| SYNC
  AUTH --> DB
  ASMT --> DB
  ASMT --> FS
  SYNC --> DB
  SYNC --> FS
  PDF --> FS

3. Class Diagram

classDiagram
  class Engineer {
    +int id
    +string full_name
    +string email
    +string phone
    -string password_hash
    +string role
    +register()
    +login()
    +updateProfile()
    +changePassword()
  }
  class Assessment {
    +int id
    +string client_uuid
    +int engineer_id
    +string owner_name
    +string building_location
    +int num_floors
    +string damage_type
    +string severity
    +string habitability
    +string status
    +string source
    +create()
    +update()
    +delete()
    +generateReport()
  }
  class Media {
    +int id
    +int assessment_id
    +string filename
    +string mime_type
    +string kind
    +int size
  }
  class Report {
    +int assessmentId
    +render()
    +toPDF()
  }
  class Contact {
    +int id
    +string name
    +string email
    +string message
  }
  class ActivityLog {
    +int id
    +int engineer_id
    +string action
    +datetime created_at
  }
  Engineer "1" --> "0..*" Assessment : creates
  Assessment "1" --> "0..*" Media : has
  Assessment "1" ..> "1" Report : generates
  Engineer "1" --> "0..*" ActivityLog : records

5. Sequence Diagram — Offline Collection & Synchronization

sequenceDiagram
  actor Eng as Field Engineer
  participant UI as PWA (Browser)
  participant IDB as IndexedDB
  participant SW as Service Worker
  participant API as Express API
  participant DB as SQLite + Files

  Note over Eng,SW: 🚫 No internet connection
  Eng->>UI: Fill assessment form + add photos
  UI->>UI: navigator.onLine == false
  UI->>IDB: Save pending record (client_uuid + base64 media)
  IDB-->>UI: stored
  UI-->>Eng: "Saved offline — will sync later"

  Note over Eng,DB: 📶 Connectivity restored
  UI->>UI: 'online' event fires
  UI->>IDB: Read all pending records
  IDB-->>UI: [pending...]
  UI->>API: POST /api/sync { assessments + media }
  API->>DB: Upsert by client_uuid (+ save media files)
  DB-->>API: created / updated ids
  API-->>UI: results [{client_uuid, server_id, status}]
  UI->>IDB: Delete successfully synced records
  UI-->>Eng: "Synced N record(s)"
